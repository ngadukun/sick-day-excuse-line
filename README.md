The funniest sick-day excuse — technically a lie, emotionally a sworn affidavit. It blames the furniture, which cannot testify against you:

> **I can't come in today — my bed has filed for full custody of me.**

## Run it

```sh
python3 main.py
```

Prints the excuse to stdout and nothing else. Python standard library only, deterministic, no files written.
